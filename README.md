# Abhay Deshmukh — Engineering Portfolio

A responsive, static portfolio spanning VLSI/RTL, industrial automation and controls, embedded systems, ECE/communications, software, and machine learning. Built with plain HTML, CSS, and JavaScript; there is no build step or package installation.

## Run locally

Open `index.html` in a modern browser. Google Fonts are used when internet access is available; system fallbacks are provided.

## Included

- Searchable, filterable gallery with 12 project cards across 7 domain filters (Robotics shows an honest empty state)
- Engineering domains, skill groups, internship, certifications and participation
- Five role-specific resume PDFs: automation/PLC, embedded/communication, software/ML, VLSI/RTL, and PCB/hardware
- Editable DOCX for the VLSI/RTL resume
- Light/dark theme toggle and responsive mobile navigation
- Direct GitHub links where a matching public repository is available

## Project-link notes

The public GitHub profile currently includes direct repositories for the ALU, FIFO, UART transmitter, modulation classifier, supply-chain app, Iris predictor, RentEase frontend, and an image-processing repository. Automation and some embedded projects are listed from the provided resume content; where no dedicated public repository was found, the card links to the GitHub profile and identifies that no direct repository is linked.

Robotics is represented as an interest/focus area connected to embedded systems, sensors, and control sequencing. No standalone robot build is claimed because one was not documented in the supplied resumes or the reviewed GitHub repositories.

## Publish with GitHub Pages

1. Create or choose a public repository for the portfolio.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `assets/` folder to the repository root.
3. Open **Settings → Pages** and select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. Open the published URL shown in repository settings.
